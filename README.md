# Portfolio Dashboard

Interactive portfolio dashboard and investment growth simulator built with React + Vite.

## Features

- Portfolio allocation visualization
- Investment growth simulation
- Expected annual growth calculation
- Dividend & reinvestment projection
- Dynamic stock allocation controls
- Responsive dashboard UI
- Real-time portfolio adjustment

## Tech Stack

- React
- Vite
- JavaScript
- Recharts
- Tailwind CSS
